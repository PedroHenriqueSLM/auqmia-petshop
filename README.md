# Au Q Mia — Petshop | Fase 2

Projeto acadêmico de Sistemas Web para evolução da Fase 1.

## Objetivo da fase 2
Tornar o sistema mais atrativo e dinâmico com CSS/Bootstrap e JavaScript, incluindo carrossel, função temporal, busca de produtos, cadastro do cliente/pet e agendamento de banho e tosa.

## Tecnologias
- HTML5 semântico
- CSS3 (`css/style.css`)
- Bootstrap 5.3.3 via CDN
- JavaScript (`js/script.js`)
- GitHub Pages para publicação

## Estrutura
- `index.html` — página inicial e carrossel
- `produtos.html` — catálogo com busca dinâmica
- `servicos.html` — serviços e links para agendamento
- `agendamento.html` — formulário de cliente, pet e agendamento
- `contato.html` — contato e autoria
- `css/style.css` — customizações visuais
- `js/script.js` — funções JavaScript
- `assets/` — imagens e logotipo

## Recursos da fase 2
1. Layout responsivo com Bootstrap.
2. Carrossel de destaques na página inicial.
3. Relógio/data atual atualizados automaticamente a cada segundo.
4. Busca de produtos em tempo real.
5. Validação dos campos obrigatórios do formulário.
6. Calendário (`input type=date`) e horário (`input type=time`) para agendamento.
7. Seleção de banho e tosa com tele-busca ou entrega do pet no local.
8. Resumo do agendamento exibido com JavaScript após validação.
9. Acessibilidade com `alt` descritivo, labels associados, navegação por teclado, link para pular conteúdo, `aria-live` e foco visível.

## Observação
O formulário é demonstrativo e não envia dados para um servidor. Nesta fase, a validação e o resumo são feitos no navegador.

## Publicação
Para GitHub Pages, use a branch `main` e a pasta `/ (root)` em Settings > Pages.
