# Au Q Mia — Petshop

Projeto acadêmico da Fase 1 da disciplina de Sistemas Web.

## Objetivo
Desenvolver a estrutura inicial de um sistema web para um petshop, apresentando produtos e serviços de forma organizada, com navegação entre páginas e informações básicas de contato.

## Tecnologias utilizadas
- HTML5
- Git e GitHub
- GitHub Pages para publicação

> Nesta Fase 1 não foram utilizados CSS, Bootstrap ou JavaScript.

## Estrutura
- `index.html` — página inicial
- `produtos.html` — categorias e produtos
- `servicos.html` — serviços de banho e tosa
- `contato.html` — informações de contato e projeto
- `assets/` — pasta reservada para recursos visuais do projeto

## Conteúdo
O catálogo contém 18 produtos, sendo:
- 6 acessórios
- 6 rações não perecíveis
- 6 produtos de higiene e limpeza

Também são apresentados os serviços:
- banho e tosa sem tele-busca
- banho e tosa com tele-busca

## Como executar
Abra o arquivo `index.html` em um navegador ou publique o conteúdo deste repositório pelo GitHub Pages.
